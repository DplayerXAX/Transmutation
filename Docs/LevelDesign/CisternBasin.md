# 腐蚀盆地 Cistern Basin

只用水相关的生物组成的区域：**腐蚀水、水蜗牛、矿石巨兽、晶石幼虫**。

场景：`Assets/Scenes/Scene_CisternBasin.unity`
生成器：**Tools > Capstone > Cistern Basin > Build New Scene**（`Assets/Scripts/Editor/CisternBasinSetup.cs`）
地形：`Assets/Terrain/Sculpted/Scene_CisternBasin_Terrain.asset`（可在 Sculpt And Place 窗口继续手工雕刻）

## 生态逻辑

水在低处，矿在高处（巨兽背上），蜗牛是唯一能把两者连起来的东西，玩家负责搬蜗牛。

- **水**：北边山坡上的泉眼顺着冲沟流进主水池；两个侧水池各有一个小渗水点；腐蚀雨在玩家附近随机下。
- **蜗牛**：住在水池边，喝满水后满壳的水会让它变老；没水时会跟着最近的巨兽。
- **巨兽**：每只沿自己的固定路线（`OreColossus.route`）走，在每个歇脚点都跪下放尾巴坡。
- **幼虫**：巨兽的矿心碎了才掉出来，它的不老光环可以当作蜗牛的中转站。

## 三只巨兽的进度

1. **A · 守池者**：歇脚点在 (-17, -2) 和 (19, 4)，离主水池约 20 m。教学关：抓蜗牛，走上尾巴坡，喷矿心。
2. **B · 环行者**：歇脚点在 (58, -14) 和 (42, -46)，东边是干地，离最近的水池 50 m 以上。喝满水的蜗牛一路都在变老，所以要用 A 掉出的幼虫在半路当不老中转站。
3. **C · 台地守卫**：歇脚点在 (-62, -24) 和 (-53, -36)，在 9 m 高的西台地上。难点是高度加距离。

## 装饰

全部使用 `Assets/Prefabs/WorldDecor` 里现有的装饰预制体，放在场景的 `Cistern Basin Decor` 节点下，约 720 件（其中矿石类约 350 件）。重新生成：**Tools > Capstone > Cistern Basin > Rebuild Decor (Open Scene)**，同一随机种子，结果固定。

| 分组 | 内容 |
| --- | --- |
| 池岸 | 贝壳床加青色矿晶壳，没有碰撞，不挡蜗牛；每个池子上方有一盏青色点光源 |
| 冲沟 | 两岸的石块和侵蚀石鳍；泉眼下方架一座石拱，水从拱下流过 |
| 歇脚点 | 每个歇脚点周围散落青色矿渣（巨兽跪下时抖落的），没有碰撞 |
| 东边干地 | 风化的石拱、石环、图腾 |
| 西台地 | 坡道两侧的石堆路标、台地边缘的方尖碑、崖脚的矿脉 |
| 山脚 | 一圈大石块和石鳍 |
| 侵蚀石林 | 5 簇高大的方尖碑和石鳍，作为远景地标 |
| 地面 | 稀疏的碎石和石堆，出生点前有两根图腾 |

矿石类装饰（`BuildOreDecor`），材质沿用矿石巨兽的 Ore（青）、Geode（紫）、Heart（亮白青）、Rock：

| 分组 | 内容 |
| --- | --- |
| 矿石柱 | 4 根高大的青色矿石方尖碑，每根旁边斜靠两根小的，底部一圈碎晶，顶上一盏青光；远景地标，最先放置，占最空的地方 |
| 山脚矿脉 | 约 14 簇大青晶从山脚斜着长出来，避开泉眼 |
| 晶洞 | 7 个裂开的晶洞：一圈向外翻开的石鳍做壳，中间是紫色晶簇和一颗亮白的"心"，各有一盏紫光 |
| 矿石碎堆 | 26 处碎石堆，中间冒出几簇青晶，散在开阔地面上 |
| 冲沟矿层 | 冲沟两岸被水冲出来的小青晶，没有碰撞 |

这些都避开了水池、冲沟、巨兽路线、坡道和出生点，也和侵蚀石林、彼此之间保持距离。

水池、冲沟、巨兽路线（两侧 10 m）、坡道和出生点都留空。装饰和地形同在 Ground 层，但侵蚀只作用于地形，所以如果装饰下面的地被冲掉，装饰会悬空。为此装饰都避开了水流经过的地方。

## 参数说明

- 地壳厚度 24 m，世界侵蚀预算 2/s。泉水侵蚀率 0.12，渗水 0.05，静止倍率 0.05。默认值下，积水会在 90 秒内把 5 m 厚的池底蚀穿。
- 侵蚀雨使用 `ErosiveFluidSystem` 的默认设置，跟着摄像机走。
- F1–F4 和 Tab 是 `ErosionDemoControls` 的测试快捷键（开关水、清水、重置侵蚀）。
