# Transmutation

A Unity first-person game project with creature interactions, traversal, ecology, combat experiments, procedural terrain, and a reflection/journal space.

- [Project context](Docs/PROJECT_CONTEXT.md): project and technical orientation; consult when needed.
- [AGENTS.md](AGENTS.md): short working rules for AI contributors.
- [Design guide](Docs/DESIGN_GUIDE.md): draft for the project owner to edit; consult for design decisions.
- [Systems index](Assets/Scripts/README.md): find the relevant local README.
- [Creature index](Assets/Scripts/Creatures/README.md): shared creature contract and feature guides.

Open this repository root through Unity Hub using the version in [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt). The configured entry scene is `Assets/Scenes/Scene_MainMenu.unity`; use the relevant local guide for a particular prototype.

Local READMEs are the preferred documentation for current behavior. Keep them accurate when changing a feature, and create a concise guide if it has none.
