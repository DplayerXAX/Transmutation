# 《易行》互动灵感库

> 文档性质：候选设计，不代表已经决定进入游戏。  
> 使用方式：从现实事物、现象和游戏类型中提取有趣的互动关系，再直接使用或重新组合。游戏不必告诉玩家这些灵感在设计阶段使用的现实名称。  
> 与主设计稿的区别：本文件允许保留大量可能性；只有确认采用的内容才会进入《易行》游戏设计稿。

> 建议先阅读排版整合后的[《易行》互动设计手册](易行_互动设计手册.md)。本文件作为详细推演与原始灵感存档保留。

## 1. 从现实灵感到互动规则

现实灵感首先为设计提供可组合的行为结构。玩家看到的对象没有现实名称和熟悉外形时，通常不会自动把它等同于火、树或电池。因此，设计不需要为了避免现实联想而刻意反转每一条规律。

一个现实灵感可以拆成四层：

1. **条件**：什么情况下事情会发生。
2. **变化**：对象自身发生什么变化。
3. **传播**：变化如何影响附近对象。
4. **反馈**：变化会增强、抑制、循环还是终止自身。

例如“燃烧”可以拆成：

- 达到阈值后开始。
- 持续释放某种参数。
- 消耗自身或周围对象。
- 可能形成自我增强的传播。

这些关系可以被直接采用，也可以与其他来源重新组合。关键问题是互动本身是否有趣、是否能够被观察、是否能与其他生物形成新的动态，而不是它是否足够违背现实。

### 互动提取原则

- 设计阶段可以使用“热、压力、电、食物”等现实名称，帮助团队交流。
- 游戏不需要把这些设计名称告诉玩家。
- 规则可以遵守现实灵感，也可以为了互动效果进行改变；改变不是必须步骤。
- 保留可观察的一致性，让玩家能够通过实验学习。
- 优先判断一个互动能让玩家或其他生物做出什么有趣行为。
- 优先选择能够与至少另一种规则连接的互动，而不是孤立的一次性效果。
- 可以组合来自不同物体、动物、化学现象和游戏类型的关系。

## 2. Parameter 参数候选库

参数可以属于环境、单个生物、两个对象之间的关系，或整个区域。参数不一定需要显示为数值。

| 设计阶段名称 | 可采用的基本运作 | 可产生的玩法 | 可重组方向 |
|---|---|---|---|
| 热 / 冷 | 扩散、积累、达到阈值后转化 | 寻找源头、搬运、维持范围、连锁反应 | 与生长、相态、追逐、繁殖结合 |
| 压力 | 随高度、密度或拥挤程度变化 | 上下移动、堆叠、释放、维持深度 | 与浮力、形变、爆发、迁徙结合 |
| 湿度 / 饱和度 | 被吸收、储存、蒸发、凝结 | 灌溉、引流、等待时机、争夺资源 | 与天气、生长、黏度、携带结合 |
| 电荷 / 极性 | 相吸、相斥、中和、传递 | 瞄准、路径规划、分群、连接网络 | 与群体运动、储能、颜色交换结合 |
| 光照 / 曝光 | 被遮挡、储存、反射、消耗 | 追逐光斑、制造阴影、潜行、充能 | 与生长、注意力、捕食、路径结合 |
| 声音 / 共振 | 频率匹配、衰减、叠加、反馈 | 节奏、同步、定位、远程触发 | 与群体行为、记忆、繁殖、远程信号结合 |
| 相态 | 固、液、气或自定义状态之间转换 | 改变通路、携带方式、可互动性 | 与温度、压力、群体密度结合 |
| 黏度 | 改变移动阻力和流动速度 | 平台移动、追逐、困住或释放生物 | 与湿度、地形、捕食、运输结合 |
| 摩擦 | 决定能否停下、攀附或积累能量 | 滑行、控制惯性、路线选择 | 与速度、地形、生长路径结合 |
| 弹性 / 张力 | 拉伸、储能、回弹、断裂 | 弹射、连接、保持距离、拔河 | 与捕捉、运输、压力、群体连接结合 |
| 质量 / 浮力 | 下沉、漂浮、压住、交换质量 | 垂直探索、称重、运输、搭建 | 与高度、压力、寄生、相态结合 |
| 速度 / 动量 | 保存、转移、吸收运动 | 追逐、投掷、弹射、连锁碰撞 | 与储能、捕食、繁殖、地形结合 |
| 生长量 | 吸收资源后扩张、分枝或繁殖 | 培育、修剪、空间管理、搭路 | 与光、湿度、密度、衰败结合 |
| 饥饿 / 缺口 | 寻找特定状态或关系，而非食物 | 诱导、护送、分配、生态平衡 | 与颜色、热量、关系、记忆结合 |
| 衰败 | 随时间丢失结构、能力或信息 | 时间规划、循环利用、清理、保存 | 与分解、建造、繁殖、资源循环结合 |
| 年龄 / 阶段 | 按时间或经历改变规则 | 等待、培育、代际变化、长期计划 | 与接触次数、环境经历、繁殖结合 |
| 污染 / 寄生度 | 在对象之间传播并改变行为 | 隔离、传播、共生、风险选择 | 与能力继承、群体传播、关系变化结合 |
| 吸引 / 排斥 | 对颜色、状态、速度或声音产生趋向 | 追逐、躲避、聚群、牧养 | 与梯度、记忆、领地、捕食结合 |
| 警觉 / 恐惧 | 因刺激升高，缓慢下降 | 潜行、安抚、驱赶、制造安全区 | 与声音、视线、群体传播结合 |
| 领地 | 对空间建立所有权或影响范围 | 路线规划、边界争夺、迁徙 | 与移动生物、资源分布、繁殖结合 |
| 记忆 | 保存最近刺激、路径或对象状态 | 教导、欺骗、训练、重复模式 | 与模仿、路线、关系、声音结合 |
| 注意力 | 一次只追踪一个目标，可被转移 | 诱导、分心、瞄准、表演 | 与视线、声音、捕食、模仿结合 |
| 同步度 | 多个对象逐渐匹配节奏或状态 | 节奏、群体控制、协作、打断 | 与声音、运动、繁殖、相变结合 |
| 秩序 / 混乱度 | 结构趋于排列或扰动 | 整理、破坏、图案构建、涌现 | 与群体形态、稳定度、地形结合 |
| 稳定度 | 决定对象抵抗变化的能力 | 催化、等待、寻找突破口 | 与蓄能、延迟、爆发、相态结合 |
| 数量 / 密度 | 个体数量改变群体行为 | 聚集、分散、种群管理、群体相变 | 与繁殖、压力、同步、捕食结合 |
| 方向 / 朝向 | 朝向传播、锁定或交换 | 对齐、反射、编队、路线设计 | 与光束、风、视线、群体移动结合 |
| 颜色组成 | 颜色可积累、分离、转移或消耗 | 配色、追踪、伪装、资源转换 | 与状态、捕食偏好、繁殖、信号结合 |
| 形状复杂度 | 边、孔洞或分枝数量影响规则 | 拼合、切换功能、空间匹配 | 与生长、相态、能力数量结合 |
| 时间速率 | 局部对象变化速度不同 | 时机、预测、保存状态、异步协作 | 与衰败、节奏、运动、延迟反应结合 |

### 参数选择原则

- Demo 优先使用一个连续参数，例如热量。
- 第二个参数只有在能创造明显的新互动模式时才加入。
- 参数需要至少影响两种生物，否则它只是单个生物的隐藏状态。
- 参数最好既有空间表现，也有时间变化。
- 参数之间应能组合，但不必模拟真实物理。

## 3. 互动模式候选库

互动模式描述的是玩家或生物“被要求怎样行动”，而不是传统游戏类型名称。

| 互动模式 | 玩家层面的表现 | 生物之间的表现 | 可能产生的游戏感觉 |
|---|---|---|---|
| 时机窗口 | 在短暂状态中点击、触碰或搬运 | 一个生物只在另一生物张开时进入 | 射击、节奏、反应 |
| 瞄准 / 对齐 | 调整视角、位置或朝向 | 生物把能量束反射给下一对象 | 射击、台球、光路谜题 |
| 追逐 / 逃避 | 追上、保持距离或引诱 | 捕食、求偶、排斥、护卫 | 动作、潜行、牧养 |
| 路径规划 | 选择安全或有效路线 | 生物依次经过不同环境带 | 塔防、物流、寻路谜题 |
| 维持范围 | 把参数保持在上下限之间 | 两种生物互相增强或抑制 | 平衡、照料、烹饪 |
| 节奏 / 同步 | 按重复周期行动 | 群体逐渐同频或互相打乱 | 音乐、协作、仪式 |
| 搬运 / 布置 | 改变对象的空间关系 | 生物主动搬运或排列其他生物 | 物流、建造、自动化 |
| 连接 / 断开 | 建立传播路径 | 网络传递颜色、热或信号 | 电路、编程、管线 |
| 聚集 / 分散 | 引导群体形成密度 | 个体达到数量后发生群体相变 | 群体控制、策略 |
| 潜行 / 注意力 | 利用遮挡、静止或诱饵 | 捕食者只追踪被标记的目标 | 潜行、躲猫猫 |
| 弹射 / 动量 | 投掷、蓄力、借力移动 | 生物互相传递运动 | 平台、弹球、体育 |
| 顺序 / 配方 | 按不同顺序接触对象 | 生物经历不同对象后分化 | 炼金、组合、记忆 |
| 模仿 / 教导 | 展示动作让生物学习 | 生物复制邻居的节奏或路径 | 训练、编程、表演 |
| 交换 / 交易 | 用一种状态换取另一状态 | 两种生物互换颜色、质量或记忆 | 资源分配、经济 |
| 寄生 / 搭乘 | 借用生物能力或被其影响 | 一个生物改变宿主行动 | 载具、共生、风险收益 |
| 观察 / 预测 | 根据规律提前行动 | 生物预测另一对象未来位置 | 推理、策略、实验 |
| 地形改造 | 诱发道路、洞穴或平台出现 | 生物的移动持续改变地形 | 平台、探索、建造 |
| 身份转换 | 玩家或生物暂时采用另一套规则 | 捕食后继承被捕食者行为 | 角色切换、职业组合 |

## 4. 可复用的 Dynamic 动态结构

这些结构能让少量生物产生持续变化，而不是只播放一次固定反应。

### 4.1 阈值

参数积累到某一点后突然改变状态。适合产生 anticipation、时机窗口和明显反馈。

例：一个生物吸收颜色；接近饱和时开始闪烁，玩家只有在闪烁的短暂阶段触碰它，才能改变释放方向。

### 4.2 滞后

进入某状态和离开该状态使用不同条件，使状态不会在临界点反复抖动。

例：生物在热量达到 70 时展开，但必须降到 30 以下才会闭合。玩家可以暂时移走热源，而展开状态仍保留一段时间。

### 4.3 延迟结果

原因与结果之间存在可观察的等待时间，鼓励预测而不是即时试错。

例：一个对象被照亮后不会马上变化，而是在三次脉动后复制最近接触过的生物行为。

### 4.4 正反馈

变化会增强导致变化的条件，形成爆发、传播或失控。

例：热使生物移动更快；移动产生更多热；群体最终形成高速旋涡。

### 4.5 负反馈

变化会削弱自身条件，形成稳定、呼吸或周期。

例：生物因热展开，展开后遮挡热源，于是降温并重新闭合，形成自发循环。

### 4.6 捕食—繁殖循环

一种生物消耗另一种，同时制造对方或第三种生物需要的条件。

例：甲吃掉紫色状态的乙并产生丙；丙降低环境稳定度，使新的乙更容易出现。

### 4.7 催化与抑制

对象不直接提供资源，只改变另一反应发生的速度或阈值。

例：透明生物经过时，两个平时不会融合的对象可以短暂交换形状。

### 4.8 空间梯度

参数在空间中形成方向，让生物行为具有可追踪的路径。

例：生物不追逐热源本身，而是沿温度上升最快的方向移动。玩家可以通过移动多个源制造岔路。

### 4.9 相变

群体数量、密度或同步度达到条件后，整体规则改变。

例：三个个体各自缓慢爬行；达到七个后融合成能够承载玩家的流动地面。

### 4.10 生态位交换

生物互动后互换功能，而不是单纯生成或消灭对象。

例：发热者接触追热者后，前者开始追逐，后者留在原地发热。

### 4.11 信息传播

传播的不是物质，而是方向、颜色、记忆、警觉或行为模式。

例：一个生物发现玩家后发出不可见信号；信号经过多个生物时被逐渐改变，最后让远处群体开始模仿玩家移动。

### 4.12 多义线索

同一视觉信号可能有多个原因，但结合过程和上下文可以判断。

例：红色可能是固有颜色，也可能是升温结果；只有逐渐变红、附近对象同时加速和产生波纹时，才形成较强的“热”证据。

## 5. 具体生物设计种子

以下每个设计都可以更换外观、名称和现实对应关系。

### 5.1 脉冲体

- 周期性释放一个扩散参数。
- 被玩家移动后，整个区域的节奏中心随之改变。
- 多个脉冲体接近时逐渐同步，也可能发生相位抵消。
- 可产生节奏、布置和预测玩法。

### 5.2 阈值花

- 吸收附近参数，到达阈值后短暂展开。
- 展开期间可以被玩家触碰、被另一生物进入或释放种子。
- 展开时间取决于此前积累速度，而不固定。
- 可产生时机窗口和培育玩法。

### 5.3 趋向兽

- 不锁定具体目标，而是比较周围某个参数的高低，例如哪里更热，并朝数值更高的方向移动。
- 多个参数源会使它摇摆、绕行或停留在平衡点。
- 玩家可以通过移动参数源“画出”路线。
- 可产生牧养、路径规划和引诱玩法。

### 5.4 储相囊

- 保存最近接触到的参数状态。
- 在受到冲击、声音或压力时一次性释放。
- 储存期间视觉只提供模糊提示，玩家需记住它吸收过什么。
- 可产生搬运、炸弹、运输和延迟连锁玩法。

### 5.5 反色寄生体

- 附着在宿主上，把宿主对参数的反应反转。
- 原本追热的生物变为逃离热；原本受压下沉的生物开始上浮。
- 寄生不是纯负面，可能帮助玩家进入新区域。
- 可产生能力修改、共生和实验玩法。

### 5.6 影食者

- 消耗遮挡关系，而不是消耗对象。
- 当两个对象形成阴影时，它沿阴影移动并逐渐增长。
- 玩家移动光源或对象即可改变其道路。
- 可产生光路、潜行和空间布置玩法。

### 5.7 质量交换者

- 接触两个对象后交换它们的质量，但不交换体积和外观。
- 轻小物可能突然压住地面，巨大物可能漂浮。
- 玩家不能直接选择交换结果，只能安排接触顺序。
- 可产生称重、平台和物理喜剧。

### 5.8 回声模仿者

- 记录附近对象的一段运动或节奏，并在延迟后重演。
- 多个模仿者可以形成越来越失真的动作链。
- 玩家能够通过自己的移动教会它简单模式。
- 可产生编程、节奏和不可预测群体行为。

### 5.9 凝结云

- 吸收分散在环境中的某参数，并在饱和后落下对象。
- 落下的对象性质取决于它经过的区域，而不是吸收总量。
- 可以成为生态循环中的移动运输者。
- 可产生等待、天气预测和区域连接。

### 5.10 边界兽

- 身体周围形成一个移动区域，区域内规则与外部不同。
- 其他生物可能把它当作栖息地、交通工具或危险区。
- 玩家进入其范围时，移动或视觉规则暂时改变。
- 可产生移动关卡和巨兽背部世界的雏形。

### 5.11 注意捕食者

- 只在玩家或其他生物观察它时移动，或者采用相反规则。
- 它可能争夺“被观察”这一资源，而不是捕食身体。
- 多个此类生物能让视角本身成为空间控制工具。
- 可产生潜行、视线管理和心理压力，但不需要伤害玩家。

### 5.12 稳定壳

- 平时抵抗所有变化，同时积累受到的影响。
- 达到极限后一次性把积累的变化以另一形式释放。
- 玩家无法从单次作用中判断结果，需要观察历史。
- 可产生蓄力、风险判断和大型事件。

### 5.13 路径苔

- 在生物经常经过的位置生长。
- 生长后改变摩擦、速度或吸引力，使路径得到进一步强化。
- 玩家能够通过反复行走或引导生物建立道路。
- 可产生蚁群路径、地形塑造和自发物流。

### 5.14 关系食者

- 不吃生物，而是吃掉两个生物之间的吸引、同步或敌对关系。
- 被吃掉关系的双方可能暂时互不影响。
- 食者消化后把该关系赋予下一对接触对象。
- 可产生社会网络、规则搬运和意外联盟。

### 5.15 分枝预言体

- 根据当前环境展示几种可能的未来形态。
- 真正发生哪一种取决于随后第一个接触它的对象。
- 玩家可以观察形态变化预测区域状态，但不能得到文字答案。
- 可产生推理、选择和预告反馈。

### 5.16 腐生建造者

- 只利用进入衰败阶段的对象搭建结构。
- 玩家若大量生产某生物，最终会间接为它提供大量材料。
- 它的结构可能改变生态路线，而非简单奖励工业化。
- 可产生循环利用、后果和非预设工业系统。

## 6. 三至四种生物的组合方案

## 6.1 组合 A：脉热猎场

**主要参数：** 热 / 冷  
**生物数量：** 3；可选第 4 种  
**适合 Demo：** 很高

组成：

1. **脉冲体**：周期性释放热量，可以被玩家搬运。
2. **阈值花**：吸热后变色并短暂展开。
3. **趋向兽**：比较周围哪里更热并向该方向移动；只在花展开时与它融合或交换状态。
4. **可选冷却体**：吸收热并漂浮，到达一定高度后落下并释放冷量。

动态：

- 脉冲体让花周期性展开，寻迹者因此形成往返或聚集。
- 玩家移动脉冲体，可以改变花的展开顺序和寻迹者路线。
- 冷却体加入后形成负反馈，系统可能自行呼吸或振荡。
- 限时展开产生反应游戏感；搬运热源产生布置和牧养感。

特点：

- 一个参数已经足以形成空间、时间和生物互动。
- Shader 可以同时展示参数扩散、生物状态和时机窗口。
- 因果链容易在演示中被观众看懂。

## 6.2 组合 B：压潮花园

**主要参数：** 压力 / 高度、质量  
**生物数量：** 4  
**适合 Demo：** 高

组成：

1. **浮囊**：低压时上升，高压时收缩并下沉。
2. **质量交换者**：交换两个接触对象的质量。
3. **凝结云**：在高处吸收分散参数，饱和后落下种子。
4. **路径苔**：在落点与移动路径上生长，改变地面弹性。

动态：

- 浮囊携带其他生物上下移动。
- 质量交换可能让云下沉、让沉重种子升起。
- 种子反复落下形成路径苔，逐渐改变浮囊的弹跳轨迹。
- 玩家通过搬运和堆叠改变垂直循环，而不需要按钮或工具。

特点：

- 具有平台、运输和天气循环的感觉。
- 垂直空间表现强，适合展示巨兽背部或高低地形。
- 物理调试成本高于组合 A。

## 6.3 组合 C：异极群落

**主要参数：** 极性、电荷、饱和度  
**生物数量：** 3–4  
**适合 Demo：** 中

组成：

1. **分极虫**：周期性改变极性，吸引或排斥同伴。
2. **储相囊**：储存接触到的电荷并在撞击时释放。
3. **中和花**：吸收相反极性后展开，释放无极性种子。
4. **可选寄生体**：反转宿主极性反应。

动态：

- 群体随周期聚集和爆散，形成可预测但不断变化的空间节奏。
- 玩家搬运储相囊，可以在目标位置制造一次群体重排。
- 寄生体会把稳定循环变成偏移或旋转运动。
- 产生弹球、瞄准、群体控制和连锁爆发的感觉。

特点：

- 视觉冲击强。
- 多体物理和群体稳定性需要较多调试。

## 6.4 组合 D：光债森林

**主要参数：** 光照、储存量、注意力  
**生物数量：** 4  
**适合 Demo：** 中

组成：

1. **储光柱**：吸收光后逐渐变暗，饱和时释放定向光束。
2. **影食者**：沿阴影移动并消耗遮挡关系。
3. **注意捕食者**：只在被观察时改变位置或状态。
4. **反光群**：根据群体朝向反射光束。

动态：

- 玩家移动和观察会同时改变光路、阴影与注意捕食者。
- 影食者吃掉阴影后使储光柱暴露，改变下一次光束方向。
- 反光群被光束击中后重新排列，进一步改变整个区域。
- 产生潜行、瞄准、光路和视线管理的混合玩法。

特点：

- Shader 与机制高度统一。
- 同时调试摄像机视线、阴影和 AI，短期 Demo 风险较高。

## 6.5 组合 E：回声迁徙

**主要参数：** 共振、同步度、记忆  
**生物数量：** 3  
**适合 Demo：** 高

组成：

1. **脉冲体**：发出稳定节奏。
2. **回声模仿者**：延迟重演最近观察到的节奏或移动。
3. **迁徙群**：同步度达到阈值后整体朝某方向移动。

动态：

- 玩家移动或点击产生一个简单节奏，模仿者逐个传播并失真。
- 迁徙群根据最终节奏选择方向或形态。
- 多个延迟形成卡农、波浪或意外反相。
- 产生音乐、编程、群体控制和表演感。

特点：

- 不依赖复杂物理。
- 需要非常清楚的声音与动画反馈。
- 可能偏离当前以拖拽生物为主的操作设想。

## 6.6 组合 F：腐生工坊

**主要参数：** 生长、衰败、密度  
**生物数量：** 4  
**适合 Demo：** 中低

组成：

1. **复制芽**：在特定密度下快速繁殖。
2. **腐生建造者**：利用衰败对象搭建路径或容器。
3. **关系食者**：移走复制芽之间的聚集关系，使群体停止繁殖。
4. **搬运群**：沿路径苔或建造结构运输对象。

动态：

- 玩家可以把复制芽集中起来，形成类似工业生产的结果。
- 大量复制芽最终衰败，为建造者提供材料。
- 建造结构又改变搬运路线和群体密度。
- 游戏不奖励或谴责工业化，只呈现它带来的生态与空间后果。

特点：

- 很贴合玩家自定目标与永久后果的主题。
- 需要较长时间才能看出变化，不适合极短演示。

## 6.7 组合 G：黏雨洼地

**主要参数：** 湿度、黏度、速度  
**生物数量：** 3–4  
**适合 Demo：** 中

组成：

1. **凝结云**：移动并在饱和时降下黏性物质。
2. **滑行兽**：移动速度随地面黏度反向变化。
3. **吸湿花**：吸收地面湿度，展开后把湿度喷向另一方向。
4. **可选路径苔**：在反复滑行处改变摩擦。

动态：

- 云改变地面，地面改变滑行兽路线，滑行兽又触发吸湿花。
- 玩家搬动花可以重新定向湿度传播。
- 系统会逐渐形成赛道、陷阱或自循环路线。
- 产生竞速、牧养、地形绘制和流体玩具感。

## 6.8 组合 H：秩序结晶

**主要参数：** 秩序度、形状复杂度、稳定度  
**生物数量：** 3  
**适合 Demo：** 中

组成：

1. **排列群**：靠近时自动形成规则图案。
2. **稳定壳**：吸收排列带来的秩序，并在饱和后爆发为随机运动。
3. **分枝预言体**：根据当前秩序展示几种未来形态。

动态：

- 群体整理自身，稳定壳缓慢积累，随后把秩序重新打散。
- 玩家移动单个对象可以延迟、提前或改变爆发方向。
- 预言体给出视觉线索，但不明确告诉玩家哪种未来会发生。
- 产生整理、预测、风险管理和循环宇宙的感觉。

## 7. Demo 选择建议

如果目标是用最短时间证明项目核心，优先顺序建议为：

1. **组合 A：脉热猎场**——最容易理解，最能同时展示 Shader、参数和玩家介入。
2. **组合 E：回声迁徙**——代码和物理可能较简单，但需要声音与动画能力。
3. **组合 B：压潮花园**——空间表现好，但物理稳定性风险更高。

最小版本可以只实现组合 A 的前三种生物：

- 一个持续改变环境参数的生物。
- 一个达到阈值后改变视觉和状态的生物。
- 一个追踪参数梯度并与第二种生物互动的生物。
- 玩家只需要能够移动第一种生物。

这个组合已经能展示：

- 世界自行互动。
- 参数在空间和时间中传播。
- Shader 表现状态而不只是装饰。
- 玩家通过简单动作改变生态关系。
- 同一套规则可以产生时机、布置、追逐和观察等不同互动感觉。

## 8. 后续筛选问题

1. Demo 最希望突出视觉陌生化、生态连锁，还是玩家产生新玩法？
2. 当前技术上最容易实现的是数值扩散、物理运动、群体 AI，还是节奏与动画？
3. 参数是否需要真实地在空间中连续扩散，还是用范围和距离近似即可？
4. 玩家在 Demo 中是否只移动生物，还是还需要一次限时点击互动？
5. Demo 是否需要让观众自行发现规律，还是由演示者口头引导？

## 9. 炼金术来源扩展

历史来源只用于扩大设计联想，不代表游戏必须准确再现某一种炼金术体系。七种行星金属通常列为金、银、水银、铜、铁、锡、铅；硫磺、水银、盐也可作为另一组三原质灵感。以下性质均为游戏创作方案，而非历史定义。

### 9.1 金：固定、保存、永恒

#### 金壳

- 接触一个正在变化的生物后，保存它当时的状态。
- 被保存者停止衰败、成长和变形，但仍能移动。
- 第二次接触会解除固定，并一次性继续此前积累的变化。
- 与花结合：永久保持开放，成为其他生物持续使用的入口。
- 与寄生体结合：寄生关系被固定后无法自行脱落。
- 玩法：保存时机、延迟释放、建立永久设施。

#### 金痕

- 不保存对象，而是保存某个空间位置最近发生过的规则。
- 其他生物经过金痕时，会短暂重复该位置过去的变化。
- 与蒸汽结合：保存一次喷发，之后任何生物经过都会再次被向上推。
- 玩法：记录路径、复制事件、用过去改造未来。

### 9.2 银：反射、复制、周期

#### 银镜兽

- 复制最近一个对它生效的互动，并把效果反射给来源。
- 它不复制对象，只复制“加热、追逐、变色、吸引”等关系。
- 与电力结合：形成反射电弧。
- 与捕食者结合：把“被追逐”关系反向交给捕食者。
- 玩法：反弹、借力、关系交换。

#### 银相花

- 在多个周期状态之间变化，每个状态允许一种不同互动。
- 周期不必对应现实月相，可以由附近生物数量决定。
- 与云结合：不同相位分别吸云、降雨、放风。
- 玩法：等待、预测、安排顺序。

### 9.3 水银：流动、传递、转化

#### 水银滴群

- 小滴会进入其他生物，读取一个参数后离开并带走它。
- 进入下一个宿主时把参数传给对方。
- 可以搬运热量、颜色、年龄或吸引关系。
- 与金壳结合：把固定状态从一个对象转移到另一个对象。
- 玩法：运输、接力、污染传播。

#### 易形水银兽

- 接触生物后暂时采用其运动方式，但不采用其目标。
- 接触云后漂浮，接触动物后追逐，接触花后扎根。
- 多次接触时只保留最近一次形态。
- 玩法：教学、能力组合、创造临时工具生物。

### 9.4 铜：传导、连接、亲和

#### 铜蔓

- 在反复发生互动的两个对象之间生长连接。
- 连接后，一端的参数变化会传到另一端。
- 与花结合：一朵花开放时让远处另一朵同时开放。
- 与蒸汽结合：构成压力管路。
- 玩法：布线、自动化、远程触发。

#### 铜亲兽

- 不追逐个体，而是追逐正在形成的新关系。
- 两个生物即将融合、捕食或同步时，它会靠近并强化该关系。
- 与寄生体结合：加速寄生传播，但也加强共生收益。
- 玩法：催化、风险收益、关系放大。

### 9.5 铁：方向、力量、冲突

#### 铁针兽

- 始终朝向区域内最强的参数梯度。
- 周围生物会逐渐与它对齐，形成队列或箭头群。
- 与风结合：成为可移动风向标并改变群体迁徙。
- 与电力结合：对齐后形成导电通路。
- 玩法：瞄准、编队、路线规划。

#### 铁食者

- 只攻击高速或强烈变化中的对象。
- 吃下目标后获得其动量，并沿同一方向冲刺。
- 与泡泡结合：泡泡破裂会吸引铁食者，形成可布置的诱饵。
- 玩法：诱导冲撞、躲避、利用敌对关系做功。

### 9.6 锡：扩张、放大、繁盛

#### 锡鸣囊

- 接收一个信号后，以更大的范围和更慢的速度重新释放。
- 多个锡鸣囊连接会把小动作放大成区域事件。
- 与声音结合：形成远距离节奏网络。
- 与热结合：把一次局部升温扩展为低强度热浪。
- 玩法：放大、广播、谨慎控制连锁规模。

#### 锡胀兽

- 每次接受不同种类的互动都会增加一个身体分枝。
- 分枝数量决定它能同时影响多少对象。
- 衰败时分枝脱落并成为独立小生物。
- 玩法：培育、复杂度管理、生命周期规划。

### 9.7 铅：重量、迟缓、积累、衰老

#### 铅坠

- 吸收附近对象的速度与浮力，使它们减慢和下沉。
- 自身会越来越重，最终压开地形或进入地下区域。
- 与云结合：把云拖低并使其凝结。
- 与蒸汽结合：压住喷口，积累更大的延迟爆发。
- 玩法：镇压、蓄压、改变垂直空间。

#### 铅忆兽

- 吸收对象的年龄或衰败，使对方恢复早期状态。
- 被吸收的时间不会消失；铅忆兽破裂时会一次性返还。
- 金壳可以把它固定成长期保存装置。
- 玩法：恢复、时间债务、不可逆风险。

### 9.8 三原质灵感：硫磺、水银、盐

#### 硫磺：启动与欲望

- **硫跃体**：降低附近所有反应的启动阈值，让平静系统突然活跃。
- **硫欲虫**：让宿主更强烈地追逐自己原本偏好的目标。
- 它们不必表现为燃烧；核心是“使潜在倾向开始行动”。

#### 水银：媒介与流动

- 搬运参数、规则或身份。
- 让平时分离的两个系统短暂交换信息。
- 可以成为所有组合中的“连接者”。

#### 盐：边界、形状与保存

- **盐晶群**：从参数梯度边界处结晶，把模糊的范围变成实体结构。
- **盐膜**：选择性允许某些参数通过，阻挡其他参数。
- 与泡泡结合：改变膜的通透性；与花结合：保护种子但阻止授粉。
- 玩法：过滤、分区、建造、保存。

### 9.9 炼金操作作为生物行为

#### 煅烧兽

- 把复杂对象逐渐分解成少量稳定属性。
- 被分解的形状消失，但属性可以被其他生物吸收。

#### 固定兽

- 在正确时机停止正在进行的反应。
- 停得太早和太晚会留下不同状态。

#### 溶解池

- 暂时取消个体边界，使多个对象共享参数。
- 离开后重新形成的个体可能拥有混合属性。

#### 蒸馏云

- 从一个对象中优先带走最容易移动的属性。
- 在高处凝结后，把该属性交给另一个对象。

#### 分离虫

- 把复合对象拆成不同方向移动的组成部分。
- 玩家可以利用地形分别捕获这些部分。

#### 发酵床

- 让衰败对象经过延迟后产生不同的新对象。
- 过程需要维持一定温度、密度或封闭状态。

#### 倍增体

- 不复制生物，只放大它接收到的下一次作用。
- 与金、银、锡组合时可能形成非常强的反馈链。

#### 投射体

- 把自己当前状态远距离赋予接触点的对象。
- 可以作为炼成链最后一步，也可以造成意外传播。

## 10. 花与植物来源扩展

### 10.1 触碰花

- 被触碰后迅速闭合，把触碰者或一个参数暂时困在内部。
- 闭合期间逐渐转化捕获内容；重新开放时释放另一状态。
- 泡泡可以阻止它完全闭合，寄生体可以改变它选择捕获的目标。

### 10.2 授粉网络

- 每朵花保存最近接触者的一部分颜色或行为。
- 搬运者依次访问两朵花后，让第二朵生成混合状态。
- 访问顺序不同会产生不同后代。
- 玩法：路线、配方、生态物流。

### 10.3 追光花

- 花的朝向会追踪移动参数源，并为其他生物提供方向。
- 多朵花可以把光、风或声音逐级反射。
- 铁针兽能够强迫花群统一朝向。

### 10.4 捕食花

- 只在目标呈现特定颜色、速度或节奏时张开。
- 它不必杀死目标，可以交换状态、孵化第三种生物或暂时改变路线。
- 玩家能制造目标状态来选择花捕获谁。

### 10.5 根网

- 地表个体彼此分离，地下却共享热量、湿度或记忆。
- 玩家移动一朵花，可能切断整个网络。
- 寄生体进入根网后会远距离传播；盐膜可以隔离网络。

### 10.6 爆种花

- 在风、压力或温度达到条件时向外发射种子。
- 发射方向取决于花此前面对的对象。
- 种子落点形成路径、食物或临时参数源。

### 10.7 嫁接体

- 接触两种植物后，把一方的触发条件与另一方的输出组合。
- 例如“遇光开放”与“开放时释放冷量”可以成为一个新个体。
- 它是把机制模块真正重新组装的生物。

## 11. 蒸汽、风与云来源扩展

### 11.1 锅炉兽

- 吸收某种对象后积累压力，达到阈值时从固定方向喷发。
- 玩家能改变喷口方向，但不能直接决定喷发时间。
- 铅坠可以延迟喷发，硫跃体会提前触发。

### 11.2 冷凝链

- 蒸汽状生物随高度或冷量聚集，形成可以携带的液滴生物。
- 液滴落地后再次成为地面生物或被花吸收。
- 形成垂直生态运输循环。

### 11.3 蒸汽骑乘体

- 本身无法移动，但会搭乘任何上升流。
- 它经过其他对象时携带并传播状态。
- 玩家通过布置锅炉兽决定它的航线。

### 11.4 风牧者

- 不产生风，只让已有风向逐渐弯曲到自己的朝向。
- 多个风牧者形成弯曲通道，可运输云、种子和泡泡。
- 铁针兽能让风牧者对齐，产生强烈直线气流。

### 11.5 涡旋巢

- 当相反方向的风相遇时出现。
- 它会捕获经过的小生物，并按重量分层释放。
- 可能自然变成分类器、运输中心或捕食陷阱。

### 11.6 记忆云

- 吸收经过区域的颜色、声音或运动模式。
- 降雨时把记忆分散赋予地面生物。
- 云经过不同生态区后，会给远方带去完全不同的行为。

### 11.7 阴影云

- 改变的不是水分，而是地面生物的注意力或活动周期。
- 影食者沿其阴影追随；追光花则在云边缘形成方向波。

## 12. 电力来源扩展

### 12.1 电荷蚤

- 跳向极性相反的对象，落地后交换双方电荷。
- 连续跳跃形成可读的传播路径。
- 玩家移动一个对象即可重写整个跳跃网络。

### 12.2 电容囊

- 缓慢储存附近的小变化，达到阈值后一次释放。
- 与花连接时制造同步开放；与动物连接时触发群体冲刺。

### 12.3 接地根

- 吸收网络中过量电荷，使系统稳定。
- 吸收到一定程度后长出新节点，把稳定区逐步扩张。
- 移除它不会立即爆发，而会让网络慢慢失衡。

### 12.4 电弧猎手

- 只能沿已有导电链移动，无法跨越绝缘空间。
- 它追逐的目标会反过来改变导电链，使追逐路线不断重写。
- 玩法：路径规划、围堵、动态迷宫。

### 12.5 开关群落

- 个体只有开与关两种状态；接触邻居时按照简单规则翻转。
- 不同排列可以形成传播波、记忆或周期。
- 玩家只移动一个个体，却能改变整个群体计算结果。

### 12.6 雷云婚配

- 两朵云积累不同极性，接近时通过地面生物放电。
- 被放电生物不会受伤，而会进入快速生长、变形或迁徙阶段。

## 13. 动物行为来源扩展

### 13.1 群聚兽

- 个体只遵守靠近、分离和对齐三条简单规则。
- 花、风和捕食者能分别改变三条规则的权重。
- 玩家移动一个影响源，可以让群体从鱼群变成圆环、队列或爆散。

### 13.2 偏色捕食者

- 只追逐具有某种颜色或变化状态的对象。
- 颜色可以由温度、花粉、电荷或固有外观造成，因此玩家需要结合上下文判断。
- 捕食后产生的不是死亡，而是第三种生物或关系。

### 13.3 领地刻画者

- 沿固定路径移动并留下边界参数。
- 同类相遇时调整边界；其他生物根据边界迁徙或繁殖。
- 玩家移动路径上的生物，可以逐渐扭曲领地而不是直接编辑地图。

### 13.4 求偶编舞者

- 只有观察到特定动作顺序才进入新阶段。
- 回声模仿者可以替玩家或其他生物完成动作。
- 错误动作不会失败，只会形成另一种关系或后代。

### 13.5 迁徙群

- 根据多个缓慢变化的参数选择下一片区域。
- 云带来记忆或湿度后，迁徙路线可能永久改变。
- 玩家不能直接命令群体，只能改变它们读取的条件。

### 13.6 蜕变兽

- 生命阶段拥有完全不同的互动角色。
- 幼体可能储热，蛹阶段固定附近变化，成体传播颜色。
- 玩家是在安排生命周期，而不是使用一个固定工具。

### 13.7 拟态者

- 模仿附近对象的视觉特征，但只复制一部分行为。
- 它能误导依赖颜色捕食的生物，也能误导玩家。
- 仔细观察变化过程仍能区分拟态与真实状态。

### 13.8 生态工程兽

- 通过日常移动持续改变地形、湿度或风路。
- 它不是关卡编辑器，却能在长时间中创造道路、池塘或屏障。
- 永久世界变化可以通过它自然发生。

## 14. 泡泡来源扩展

### 14.1 携带泡

- 包住一个小生物，使其暂时不受外部参数影响并缓慢上升。
- 泡破裂时，被包对象一次性响应沿途积累的环境变化。

### 14.2 选择膜泡

- 允许某些参数穿过，阻挡另一些参数。
- 盐膜、寄生体或花粉可以改变选择性。
- 可作为移动过滤器和临时生态区。

### 14.3 合并泡

- 两个泡接触后合并其内部参数，但内部生物仍保持独立。
- 达到容量上限后分裂，分裂结果由内部状态决定。
- 可产生混合、孵化和不可预测分配。

### 14.4 爆裂信号泡

- 破裂本身是一个可以被其他生物感知的事件。
- 不同大小决定信号范围，不同内部物决定信号类型。
- 玩家可以布置延迟信号链，而不是直接按开关。

### 14.5 泡沫群

- 单个泡功能很弱；密度达到阈值后形成可承载、隔热或堵塞的整体。
- 动物穿过泡沫会留下通路，通路又改变后续群体运动。

## 15. 寄生与共生来源扩展

### 15.1 规则反转寄生体

- 把宿主对一个参数的反应反转。
- 追热变逃热、吸光变避光、下沉变上浮。
- 它能把已有生物变成新玩法，而不需要新增完整 AI。

### 15.2 驾驶寄生体

- 不改变宿主能力，只改变宿主选择目标的方式。
- 宿主可能开始跟随玩家、云、声音或其他寄生宿主。

### 15.3 换宿寄生体

- 必须依次经历两到三个不同宿主才能完成生命周期。
- 每个宿主阶段影响一种不同参数。
- 玩家通过移动宿主决定传播路线。

### 15.4 育儿寄生体

- 把自己的种子放入其他生物产生的容器或花中。
- 宿主仍正常繁殖，但部分后代采用寄生体规则。
- 可以产生长期、难以立即发现的生态变化。

### 15.5 能力共生体

- 宿主为它提供移动或保护，它为宿主提供参数转换。
- 分开时两者都能生存，但组合后产生新互动模式。
- 适合表现“组合不是合成物品，而是形成关系”。

### 15.6 参数税

- 寄生体持续拿走宿主一小部分热量、速度或记忆。
- 它把收集物带给另一物种，意外形成区域物流网络。

## 16. 炼丹与炉鼎意象的机制候选

以下只作为创作起点；如果游戏要明确使用中国炼丹、道教或其他文化名称与符号，需要另行研究，不能把这些机制候选当作文化事实。

### 16.1 活炉

- 巨兽身体的一部分形成一个可以进入的反应空间。
- 放入顺序、停留时间、温度变化和出口方向共同决定结果。
- 活炉不是菜单式合成器，内部生物仍会自由互动。

### 16.2 循环精炼

- 对象需要多次经过加热、冷却、上升、下降或分离过程。
- 每次循环只改变一个小属性，永久积累为新形态。
- 玩家可以中途取出，得到不同但不一定较差的结果。

### 16.3 成对调和

- 两个相反参数不是互相消灭，而是产生第三种稳定运动。
- 平衡不是静止，而可能表现为围绕、呼吸或周期交换。

### 16.4 杂质生物

- 精炼过程排出的属性形成独立生物，而不是无用废料。
- 大量精炼会建立新的“废料生态”，自然回应玩家的工业化行为。

### 16.5 内部循环兽

- 参数必须沿其身体的多个节点循环，不能直接填满数值。
- 堵塞、反向流动或寄生会改变其整体行为。
- 玩家通过移动外部生物影响内部路线。

## 17. 可继续加入的现实来源

### 菌丝

- 地下网络共享资源、警报和方向。
- 地表看到的是多个个体，实际是一个分布式生物。

### 黏菌

- 通过试探多条路径，逐渐强化较有效路线。
- 可以自然生成物流和迷宫求解行为。

### 珊瑚与礁体

- 大量微小个体长期建造固定结构。
- 结构反过来改变水流、光照和其他生物栖息地。

### 发酵

- 衰败在封闭、温度与时间条件下产生新状态。
- 适合慢变化、气泡、压力和群体微生物。

### 免疫系统

- 生物根据过去接触形成识别与排斥记忆。
- 拟态者、寄生体和无害生物可能引发误判。

### 潮汐

- 整个区域参数周期性升降，开放和关闭不同路线。
- 生物把周期当作迁徙、繁殖或捕食时钟。

### 晶体生长

- 从少量种子沿局部方向规则扩张。
- 不同参数杂质改变分枝、颜色和导电性。

### 色谱与分层

- 混合状态经过移动介质时按速度逐渐分离。
- 可以把一个复杂对象拆成多个可捕获阶段。

### 振荡化学反应

- 颜色或状态无需外部周期源也会自行往复。
- 多个振荡体接触后可能同步、竞争或形成空间波。

### 火灾生态

- 强烈变化摧毁一种结构，却触发另一种生物繁殖。
- 后果不是简单恢复，而是进入新的生态阶段。

## 18. 跨来源的三至四生物组合

### 18.1 永恒花园

**组成：** 阈值花、金壳、水银滴群、腐生建造者  
**参数：** 生长阶段、固定度、衰败

- 花开放后通常会迅速衰败。
- 金壳可以保存某朵花的开放状态。
- 水银滴群可能把固定状态带到其他对象，引起意外永久化。
- 未被固定的花衰败后成为建造材料。
- 动态特点：保存一部分世界必然改变另一部分世界的资源循环。
- 游戏感觉：园艺、时间管理、永久后果、空间建造。

### 18.2 水银授粉

**组成：** 两种花、水银滴群、偏色捕食者  
**参数：** 颜色组成、访问顺序

- 水银滴在花之间搬运颜色与触发条件。
- 混合花粉产生新的花状态。
- 捕食者只追逐其中一种颜色，改变水银滴的安全路线。
- 玩家移动花或捕食者，间接设计授粉网络。
- 游戏感觉：物流、配方、护送、动态路径。

### 18.3 风暴器官

**组成：** 锅炉兽、风牧者、记忆云、电容囊  
**参数：** 压力、风向、电荷、记忆

- 锅炉兽制造上升流，把记忆云送入风路。
- 风牧者决定云经过哪些生物。
- 云积累不同状态后为电容囊充能。
- 电容释放触发锅炉下一次喷发，形成可被玩家重排的循环。
- 游戏感觉：天气操控、管线、节奏、连锁系统。

### 18.4 泡中寄生

**组成：** 携带泡、选择膜泡、换宿寄生体、迁徙群  
**参数：** 通透性、宿主阶段、浮力

- 泡保护寄生体穿过原本无法生存的区域。
- 选择膜决定它何时能接触宿主。
- 寄生后的迁徙群把它带到远处，完成下一阶段。
- 玩家改变泡膜，而不是直接把寄生体塞进宿主。
- 游戏感觉：运输、生态传播、路线规划、风险释放。

### 18.5 雷花群

**组成：** 电荷蚤、电容囊、授粉花、群聚兽  
**参数：** 电荷、花粉、同步度

- 电荷蚤在群聚兽之间跳跃，使群体逐渐带电。
- 群体接近电容囊时触发区域脉冲。
- 脉冲让所有花同时开放，释放花粉改变群体颜色。
- 新颜色又改变电荷蚤的目标选择。
- 游戏感觉：群体牧养、节奏爆发、颜色网络。

### 18.6 铅云蒸馏

**组成：** 铅坠、蒸馏云、追光花、浮囊  
**参数：** 质量、高度、光照、纯度

- 铅坠把云拖入低处，使它吸收地面对象的状态。
- 浮囊随后把云送高，云在上升过程中分离并降下不同属性。
- 追光花改变浮囊和云的水平路线。
- 游戏感觉：垂直运输、分离、天气炼成。

### 18.7 盐泡生态箱

**组成：** 盐膜、泡沫群、根网、参数税寄生体  
**参数：** 通透性、湿度、寄生度

- 盐膜与泡沫形成局部封闭生态区。
- 根网跨越膜连接内外，但只传递某些参数。
- 寄生体通过根网抽取内部资源并供给外部生物。
- 玩家改变一个膜节点，可能永久改变整个生态箱平衡。
- 游戏感觉：过滤、生态管理、边界与泄漏。

### 18.8 铁风狩猎

**组成：** 铁针兽、风牧者、偏色捕食者、爆裂信号泡  
**参数：** 朝向、风向、颜色、警觉

- 铁针兽让风牧者形成统一方向。
- 风推动信号泡进入捕食者附近，泡破裂改变其目标颜色。
- 玩家布置泡的位置和颜色，引导捕食者撞向特定对象。
- 游戏感觉：射击、诱导、风路、间接战斗。

### 18.9 发酵云田

**组成：** 发酵床、凝结云、爆种花、腐生建造者  
**参数：** 湿度、温度、衰败、压力

- 云降雨维持发酵床状态。
- 发酵产生气体推动花爆种。
- 植物衰败后成为建造者材料，结构又改变云和种子的路线。
- 游戏感觉：农业、天气、自动化、长期生态变化。

### 18.10 银镜仪式

**组成：** 银镜兽、求偶编舞者、回声模仿者、脉冲体  
**参数：** 节奏、记忆、反射关系

- 脉冲体提供基础节奏。
- 模仿者延迟复制动作。
- 银镜兽反射其中一段，让节奏形成对称或反相。
- 编舞者根据最终动作序列进入不同生命周期。
- 游戏感觉：节奏、编程、表演、观察预测。

## 19. 组合生成公式

设计新的三至四生物组合时，可以从下面四个角色各选一个：

1. **来源者**：持续产生或改变一个参数。
2. **读取者**：根据该参数移动或改变状态。
3. **转换者**：把参数变成另一种参数、对象或关系。
4. **扰动者**：延迟、反转、保存、传播或放大前三者的规则。

最简单的有效链条：

> 来源者产生条件 → 读取者作出行为 → 转换者产生新结果 → 扰动者让循环发生偏移

玩家不一定直接操作每个角色。只要能移动、阻挡或暂时触发其中一个角色，就可能改变整条链。

## 20. 新增筛选问题

1. 七金是只作为多个生物的性质来源，还是希望成为世界中明确的一套七类存在？
2. “金具有永恒”中的永恒，是停止变化、抵抗衰败、保存记忆，还是让规则永久留在空间中？
3. 炼丹灵感希望重点来自炉、火候、顺序与精炼过程，还是来自更广泛的哲学概念？
4. 花、云、电、动物等类别是否只为团队内部分类，游戏中完全不命名？
5. Demo 是否要从某一个文化或自然来源集中取材，还是刻意混合多个来源？

- Getty 的炼金操作资料说明不同来源中的阶段名称和顺序可能变化，并列出煅烧、固定、溶解、蒸馏、升华、分离、发酵等操作：<https://www.getty.edu/research/exhibitions_events/exhibitions/alchemy/booklet.pdf>
- Science History Institute 对水银—硫磺理论、蒸馏、结晶、煅烧和溶解等历史实践有所概述：<https://www.sciencehistory.org/stories/magazine/whats-in-a-name/>
