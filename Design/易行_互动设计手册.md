## 1. 核心设计方法

### 1.1 互动的基本单位

每个生物或系统尽量写清五件事：

| 项目 | 问题 |
|---|---|
| 读取 | 它观察什么参数、对象或事件？ |
| 条件 | 何时开始、停止或改变行为？ |
| 行为 | 它移动、储存、追逐、复制还是转化什么？ |
| 输出 | 它对环境或其他生物留下什么结果？ |
| 连接 | 哪些其他规则能够读取它的输出？ |

### 1.2 四角色组合公式

| 角色 | 作用 | 简单例子 |
|---|---|---|
| 来源者 | 持续产生或改变参数 | 发热、降雨、发出脉冲 |
| 读取者 | 根据参数行动或变形 | 追热、遇光开放、受压漂浮 |
| 转换者 | 把输入变成另一种状态 | 把热变成颜色，把衰败物变成结构 |
| 扰动者 | 保存、反转、延迟或放大规则 | 固定状态、改变目标、复制反应 |

最小有效链条：

> 来源者产生条件 → 读取者行动 → 转换者产生新结果 → 扰动者让循环偏移

Demo 不必拥有四个角色。前三个已经可以形成完整因果链，第四个用于制造更意外的结果。

### 1.3 筛选标准

一个候选生物越符合以下条件，越值得优先制作：

- 不依靠文字也能观察到状态变化。
- 输出能被至少另一种生物读取。
- 玩家只用移动、观察或一次简单互动就能改变结果。
- 单独运行有行为，组合后出现新的 Dynamic。
- 不需要专用 UI、物品栏或大量特殊操作。

## 2. 参数总表

参数可以属于环境、个体、两个对象之间的关系或整个区域。名称只是开发用简称。

| 参数 | 基本变化 | 适合连接的机制 | 可能产生的玩法 |
|---|---|---|---|
| 热 / 冷 | 扩散、积累、达到阈值后转化 | 生长、相态、追逐、繁殖 | 搬运热源、维持范围、连锁反应 |
| 压力 | 随高度、密度或封闭程度变化 | 浮力、喷发、形变、凝结 | 堆叠、蓄压、垂直运输 |
| 湿度 / 饱和度 | 吸收、蒸发、凝结、释放 | 云、花、黏度、发酵 | 灌溉、引流、等待时机 |
| 电荷 / 极性 | 相吸、相斥、中和、传递 | 群体、储能、导电路径 | 布线、弹射、群体重排 |
| 光照 / 曝光 | 遮挡、反射、储存、消耗 | 花、阴影、注意力、捕食 | 光路、潜行、追逐光斑 |
| 声音 / 共振 | 叠加、衰减、同步、反馈 | 记忆、群体、远程触发 | 节奏、定位、同步 |
| 相态 | 在若干身体状态间转换 | 热、压力、密度 | 改变通路、携带方式和可互动性 |
| 黏度 / 摩擦 | 改变移动阻力、停留和滑行 | 湿度、路径、捕食 | 竞速、困住、绘制路线 |
| 弹性 / 张力 | 拉伸、储能、回弹、断裂 | 压力、连接、捕捉 | 弹射、拔河、保持距离 |
| 质量 / 浮力 | 下沉、漂浮、压住、交换 | 高度、云、泡泡、相态 | 称重、运输、搭建 |
| 速度 / 动量 | 保存、转移、吸收运动 | 捕食、撞击、储能 | 投掷、追逐、连锁碰撞 |
| 生长量 | 扩张、分枝、繁殖 | 光、湿度、密度、衰败 | 培育、修剪、造路 |
| 饥饿 / 缺口 | 寻找某种状态或关系 | 颜色、热、声音、记忆 | 诱导、护送、生态平衡 |
| 衰败 | 随时间失去结构、能力或信息 | 分解、建造、发酵 | 循环利用、保存、长期规划 |
| 年龄 / 阶段 | 按时间或经历改变规则 | 蜕变、繁殖、记忆 | 培育、代际变化 |
| 寄生度 | 传播并改变宿主规则 | 群体、关系、能力继承 | 隔离、共生、风险选择 |
| 吸引 / 排斥 | 对特定状态形成趋向 | 梯度、领地、捕食 | 追逐、聚群、牧养 |
| 警觉 / 恐惧 | 因刺激升高并逐渐恢复 | 视线、声音、群体信号 | 潜行、驱赶、安抚 |
| 领地 | 空间拥有边界或影响范围 | 迁徙、繁殖、资源 | 边界争夺、路线变化 |
| 记忆 | 保存刺激、路径或对象状态 | 模仿、训练、关系 | 教导、欺骗、重复模式 |
| 注意力 | 一次追踪有限目标并可被转移 | 视线、声音、捕食 | 分心、瞄准、表演 |
| 同步度 | 多个对象逐渐匹配节奏或状态 | 声音、群体、相变 | 节奏、协作、打断 |
| 秩序 / 混乱度 | 排列、扰动或形成图案 | 群体、稳定度、地形 | 整理、破坏、涌现 |
| 稳定度 | 抵抗变化并积累影响 | 蓄能、延迟、爆发 | 催化、等待、寻找突破口 |
| 数量 / 密度 | 数量改变群体整体规则 | 繁殖、压力、相变 | 聚集、分散、种群管理 |
| 方向 / 朝向 | 对齐、锁定、反射、传播 | 光束、风、编队 | 瞄准、路线、群体控制 |
| 颜色组成 | 积累、分离、转移、消耗 | 捕食偏好、信号、繁殖 | 配色、追踪、伪装 |
| 形状复杂度 | 边、孔洞、分枝数量改变能力 | 生长、拼合、相态 | 拼装、空间匹配 |
| 时间速率 | 局部变化速度不同 | 衰败、节奏、运动 | 时机、预测、异步协作 |
| 永久度 | 抵抗变化、保存关系或留下痕迹 | 金、记忆、衰败、空间 | 固定状态、永久后果 |

### 参数使用建议

- Demo 先使用一个连续参数；温度是目前最容易理解和表现的候选。
- 第二个参数必须能改变第一条互动链，而不是只增加数值。
- 参数至少影响两种生物，否则更适合作为单体内部状态。
- 优先选择同时具有空间传播和时间变化的参数。

## 3. 互动模式总表

| 模式 | 玩家层面 | 生物之间 | 类似的游戏感觉 |
|---|---|---|---|
| 时机窗口 | 在短暂状态中互动 | 只在对方展开时进入 | 反应、射击、节奏 |
| 瞄准 / 对齐 | 调整位置或朝向 | 反射、接力、编队 | 射击、台球、光路 |
| 追逐 / 逃避 | 追上、保持距离、引诱 | 捕食、求偶、排斥 | 动作、潜行、牧养 |
| 路径规划 | 选择或制造路线 | 迁徙、运输、巡逻 | 物流、塔防、寻路 |
| 维持范围 | 把参数保持在区间 | 互相增强或抑制 | 平衡、照料、烹饪 |
| 节奏 / 同步 | 按周期行动 | 同频、反相、打断 | 音乐、协作、仪式 |
| 搬运 / 布置 | 改变空间关系 | 主动排列其他对象 | 建造、物流、自动化 |
| 连接 / 断开 | 建立传播路径 | 传递热、颜色或信号 | 电路、编程、管线 |
| 聚集 / 分散 | 引导群体密度 | 达到数量后相变 | 群体控制、策略 |
| 潜行 / 注意力 | 利用遮挡和诱饵 | 捕食者追踪有限目标 | 潜行、躲猫猫 |
| 弹射 / 动量 | 投掷、蓄力、借力 | 传递运动 | 平台、弹球、体育 |
| 顺序 / 配方 | 按不同次序接触 | 经历不同对象后分化 | 炼金、组合、记忆 |
| 模仿 / 教导 | 展示动作 | 复制邻居节奏或路线 | 训练、编程、表演 |
| 交换 / 交易 | 用状态换状态 | 交换颜色、质量或记忆 | 资源分配、经济 |
| 寄生 / 搭乘 | 借用能力或承担影响 | 改变宿主行动 | 载具、共生、风险收益 |
| 观察 / 预测 | 根据规律提前行动 | 预测其他对象未来位置 | 推理、策略、实验 |
| 地形改造 | 诱发道路与平台 | 持续改变环境 | 平台、探索、建造 |
| 身份转换 | 暂时采用其他规则 | 捕食后继承行为 | 角色切换、能力组合 |

## 4. 动态结构总表

| Dynamic | 运作方式 | 有趣之处 | 简单例子 |
|---|---|---|---|
| 阈值 | 参数达到一点后突然转态 | 制造期待和时机窗口 | 吸热到一定程度后开放 |
| 滞后 | 进入与离开状态使用不同条件 | 防止临界点抖动并保留短期记忆 | 70 展开、30 以下才闭合 |
| 延迟 | 原因与结果相隔一段时间 | 鼓励预测而非即时试错 | 三次脉动后复制行为 |
| 正反馈 | 变化加强导致变化的条件 | 传播、爆发、失控 | 移动生热，热使移动更快 |
| 负反馈 | 变化削弱自身条件 | 稳定、呼吸、自然周期 | 展开后遮挡热源并重新降温 |
| 捕食—繁殖 | 消耗一种对象并产生另一条件 | 形成生态循环 | 吃紫色对象后产生冷却者 |
| 催化 / 抑制 | 改变反应速度或阈值 | 小对象控制大系统 | 透明生物允许短暂融合 |
| 空间梯度 | 参数在空间中形成方向 | 路径可被移动源重画 | 沿升温最快方向移动 |
| 群体相变 | 数量或同步达到条件后换规则 | 少量单位产生整体行为 | 七个个体融合成流动地面 |
| 生态位交换 | 互动后交换功能 | 组合结果不是简单生成或消灭 | 发热者与追热者互换角色 |
| 信息传播 | 传播方向、警觉、颜色或行为 | 形成远距离间接后果 | 远处群体模仿玩家移动 |
| 多义线索 | 同一视觉可能有多个原因 | 鼓励结合过程判断 | 红色可能是固有色，也可能因升温 |

## 5. 生物与系统总表

### 组合的有趣特点

- **同一参数，多种读取方式**：热既能让花开放，也能引导寻迹者移动。
- **输出回到输入**：冷却体消耗热量，使系统重新进入初始阶段。
- **玩家只改一个节点**：移动热源即可改变整个链条，而不需要控制所有生物。
- **第四种生物改写规则**：寄生体、金壳或倍增体不新增资源，而是改变已有关系。
- **失败也是新状态**：过热、错过时机或错误授粉不显示失败，只形成另一种生态结果。
- **永久变化来自循环**：路径、结构、迁徙和寄生长期积累，而不是剧情按钮。

## 7. Demo 候选

### 推荐顺序

| 顺位 | 组合 | 原因 | 最小实现 |
|---|---|---|---|
| 1 | A 脉热猎场 | 因果容易看懂；Shader、参数和玩家介入能统一展示 | 3 生物、1 参数、移动热源 |
| 2 | E 回声迁徙 | 不依赖复杂物理；能展示生物生成节奏玩法 | 3 生物、同步度、简单声音反馈 |
| 3 | B 压潮花园 | 垂直空间和巨兽背部感觉较强 | 3–4 生物、压力或高度近似 |

### 最小 Demo 必须证明

1. 世界在没有玩家时也会互动。
2. 一个共享参数连接至少三种对象。
3. 玩家只做一个简单动作，就能改变整条因果链。
4. Shader 清楚表现状态变化，而不只是装饰。
5. 演示者可以快速重置场景。

### 暂不制作

- 多区域、完整巨兽 AI、物品栏、正式笔记系统。
- 生存、死亡、复杂存档和完整永久世界。
- 三个以上环境参数。
- 每种生物独立的一套玩家操作。

## 8. 尚待决定

1. “金的永恒”最终指停止变化、抵抗衰败、保存记忆，还是把关系永久留在空间中。
2. 七金是团队内部的性质来源，还是世界中明确存在的七类事物。
3. 炼丹灵感重点来自炉、火候、顺序与精炼，还是更广泛的哲学概念。
4. Demo 首要证明视觉、生态自运行、玩家改变系统，还是生物组合出新玩法。
5. Demo 采用三种还是四种生物。
6. 第一参数是否确定为温度，以及是否需要第二参数。
7. 玩家在 Demo 中只移动生物，还是还需要一次限时互动。
